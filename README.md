# fundamentals-export

Deployable snapshot of the fundamentals-pipeline project: two SQLite DBs (raw fundamentals +
analysis results/verdicts/embeddings) for 1194 validated blue-chip and international
standard-value symbols, a Flask read-only API, a static screening viewer, and a RAG analyst
chat robot -- all packaged for direct download into Replit (too large for manual upload).

See the release assets for the full `YAHOO-EXPORT.zip`.
